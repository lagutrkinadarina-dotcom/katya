# Ночная смена

Браузерный детективный прототип: 3D-коридор (Three.js), рисованные SVG-кабинеты, расследование одного убийства, три улики и три исхода.

## Запуск

Node.js 22.12+ или 24. В каталоге проекта:

```sh
npm ci --cache /tmp/katya-npm-cache
npm run dev
```

Откройте адрес, который напечатает Vite. Требуются настольный браузер с WebGL, мышь и клавиатура. `npm run build` собирает игру в `dist`; `npm run preview` запускает собранную версию.

## Управление

WASD — движение. Нажмите на коридор для захвата мыши. Мышь — обзор, ЛКМ по двери с близкого расстояния — вход. В кабинетах наведите курсор на предметы и нажмите ЛКМ. Escape — пауза или закрытие окна. Кнопка «В коридор» возвращает к прежней позиции.

## Дело № 041

Изучите папку и доску в кабинете следователя. В комнате допроса предъявите Соколовой журнал доступа. Вернитесь к телефону и запросите экспертизу. После этого завершите допрос и выберите обвинение. Неполное расследование приводит к другим исходам.

## Ограничения прототипа

Одно дело, два кабинета, архив закрыт. Для сохранения подойдите к белому телефону на столе у дальнего окна, наберите 007 и нажмите кнопку звонка. Сохранение хранится в браузере на этом устройстве; после перезагрузки выберите «Продолжить». Используйте тот же адрес и порт сервера, чтобы браузер видел сохранение. Иллюстрации созданы в SVG; звук — синтезированный фон, без озвучки. Мобильное управление пока отсутствует.

## Главное меню

«Новая игра» начинает дело заново. При наличии сохранения открывается подтверждение: «Отмена» сохраняет прогресс, «Начать заново» удаляет сохранение и сбрасывает расследование. «Продолжить» загружает телефонное сохранение и недоступно, если его нет. Escape открывает паузу: возврат в игру, настройки или главное меню. Настройки громкости и чувствительности мыши применяются сразу и сохраняются в браузере. Раздел «Автор» пока пуст. «Выход» останавливает игру и звук; обычную вкладку браузер может запретить закрывать автоматически, поэтому появляется экран завершения. Постоянные панели с названием участка, счётчиком материалов и часами убраны. Новая игра начинается с истории и роли следователя. После кнопки «Продолжить» игрок появляется у закрытой лестницы: обучение последовательно проверяет движение WASD, обзор мышью, вход в кабинет следователя, изучение папки и доски улик, затем первый вопрос на допросе. После обучения подсказки исчезают. Телефонное сохранение также запоминает этап обучения.

## Последний раунд

Новое дело: убийство спортивного журналиста Ильи Громова после турнира клуба «Ринг». Подозреваемая — боксёрша Марина «Сирень» Соколова. Персонаж и интерьер допроса используют одобренную иллюстрацию. Это 2D-сцена, а не трёхмерная модель. Изучите папку и журнал доступа, предъявите журнал Соколовой, запросите восстановление записи и экспертизу кубка в кабинете следователя, затем примите решение. Сохранения нового дела хранятся отдельно от старого дела Орлова; старый прогресс не переносится в новый сюжет.
