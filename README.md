# Ночная смена

Браузерный детективный прототип: 3D-коридор (Three.js), рисованные SVG-кабинеты, расследование одного убийства, три улики и три исхода.

## Запуск

Node.js 22.12+ или 24. В каталоге проекта:

```sh
npm ci --cache /tmp/katya-npm-cache
npm run dev
```

Откройте адрес, который напечатает Vite. Требуются настольный браузер с WebGL, мышь и клавиатура. `npm run build` собирает игру в `dist`; `npm run preview` запускает собранную версию.

## Управление

WASD — движение. Нажмите на коридор для захвата мыши. Мышь — обзор, ЛКМ по двери с близкого расстояния — вход. В кабинетах наведите курсор на предметы и нажмите ЛКМ. Escape — пауза или закрытие окна. Кнопка «В коридор» возвращает к прежней позиции.

## Дело № 041

Изучите папку и доску в кабинете следователя. В комнате допроса предъявите Орлову журнал пропусков. Вернитесь к телефону и запросите экспертизу. После этого завершите допрос и выберите обвинение. Неполное расследование приводит к другим исходам.

## Ограничения прототипа

Одно дело, два кабинета, архив закрыт. Прогресс хранится только до перезагрузки страницы. Иллюстрации созданы в SVG; звук — синтезированный фон, без озвучки. Мобильное управление пока отсутствует.
