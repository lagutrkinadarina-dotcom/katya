# Ночная смена

Браузерный детективный прототип: 3D-коридор (Three.js), рисованные SVG-кабинеты, расследование одного убийства, три улики и три исхода.

## Запуск

Node.js 22.12+ или 24. В каталоге проекта:

```sh
npm ci --cache /tmp/katya-npm-cache
npm run dev
```

Откройте адрес, который напечатает Vite. Требуются настольный браузер с WebGL, мышь и клавиатура. `npm run build` собирает игру в `dist`; `npm run preview` запускает собранную версию.

## Управление

WASD — движение. Нажмите на коридор для захвата мыши. Мышь — обзор, ЛКМ по двери с близкого расстояния — вход. В кабинетах наведите курсор на предметы и нажмите ЛКМ. Escape — пауза или закрытие окна. Кнопка «В коридор» возвращает к прежней позиции.

## Дело № 041

Изучите папку и доску в кабинете следователя. В комнате допроса предъявите Соколовой журнал доступа. Вернитесь к телефону и запросите экспертизу. После этого завершите допрос и выберите обвинение. Неполное расследование приводит к другим исходам.

## Ограничения прототипа

Одно дело, два кабинета, архив закрыт. Для сохранения подойдите к белому телефону на стойке дежурной части, наберите 007 и нажмите кнопку звонка. Сохранение хранится в браузере на этом устройстве; после перезагрузки выберите «Продолжить». Используйте тот же адрес и порт сервера, чтобы браузер видел сохранение. Иллюстрации созданы в SVG; звук — синтезированный фон, без озвучки. Мобильное управление пока отсутствует.

## Главное меню

«Новая игра» начинает дело заново. При наличии сохранения открывается подтверждение: «Отмена» сохраняет прогресс, «Начать заново» удаляет сохранение и сбрасывает расследование. «Продолжить» загружает телефонное сохранение и недоступно, если его нет. Escape открывает паузу: возврат в игру, настройки или главное меню. Настройки громкости и чувствительности мыши применяются сразу и сохраняются в браузере. Раздел «Автор» пока пуст. «Выход» останавливает игру и звук; обычную вкладку браузер может запретить закрывать автоматически, поэтому появляется экран завершения. Постоянные панели и пошаговые подсказки убраны. Новая игра начинается с истории и роли следователя. После кнопки «Продолжить» игрок появляется на первом этаже лицом к двойным дверям с табличкой «Выход». Можно спуститься на первый этаж и вернуться наверх. Нижний проход расположен слева по направлению спуска. Дежурная часть отделена стеклянной перегородкой с открытым окошком, полкой и табличкой. За стеклом стоит Лебедев: подойдите и нажмите на окно, чтобы узнать о деле, работе с уликами и сохранении. Модель дежурного построена из сглаженных поверхностей с чертами лица и деталями формы; внешние модели не загружаются. После завершения разговора с дежурным открывается доступ к двери в проходе к лестнице. ЛКМ открывает и закрывает дверь с обеих сторон. Чтобы закрыть её, отойдите от проёма. За дверью расположен путь на второй этаж; дополнительного служебного крыла нет. Состояние двери и разрешение дежурного сохраняются вместе с прогрессом.

## Последний раунд

Новое дело: убийство спортивного журналиста Ильи Громова после турнира клуба «Ринг». Подозреваемая — боксёрша Марина «Сирень» Соколова. Персонаж и интерьер допроса используют одобренную иллюстрацию. Это 2D-сцена, а не трёхмерная модель. Изучите папку и журнал доступа, предъявите журнал Соколовой, запросите восстановление записи и экспертизу кубка в кабинете следователя, затем примите решение. Сохранения нового дела хранятся отдельно от старого дела Орлова; старый прогресс не переносится в новый сюжет.


## Редактор предметов

Во время игры нажмите F2 или выберите «Редактор предметов» в меню паузы. Редактор работает с обстановкой первого этажа: мебелью, растением, батареей, светильниками, компьютером, телефоном и настенным декором.

Выберите предмет мышью или в списке справа. Перетаскивайте цветные стрелки для перемещения; кнопка «Поворот» включает кольца вращения. Координаты и угол можно ввести числом. Правая кнопка мыши вращает обзор, колесо приближает камеру. «Отменить изменение» возвращает последнее перемещение, «Исходное положение» сбрасывает выбранный предмет, «Сбросить всё» возвращает исходную обстановку.

«Сохранить расстановку» хранит её в этом браузере отдельно от прогресса расследования и применяет после перезагрузки. Для переноса на другое устройство скачайте JSON и загрузите его в редакторе. Стандартная расстановка проекта хранится в `src/default-layout.json`. Для её замены можно скопировать туда экспортированный JSON и выполнить `npm run build`; разработчик также может внести файл в проект. «Исходное положение» и «Сбросить всё» возвращают к этой стандартной расстановке. F2 или кнопка «Вернуться в игру» закрывает редактор и возвращает управление мышью. Зоны столкновения мебели и зона взаимодействия с телефоном перемещаются вместе с предметами.
