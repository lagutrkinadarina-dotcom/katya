# Модель кисти для сравнения

Превью исходной правой кисти `generic-hand/right.glb` из `@webxr-input-profiles/assets` версии 1.0.18. Это обзор кандидата для замены кисти игрока; игровая модель в этом коммите не меняется.

- [Ладонь](previews/hand-source-back.png)
- [Тыльная сторона](previews/hand-source-front.png)
- [Исходный GLB](https://cdn.jsdelivr.net/npm/@webxr-input-profiles/assets@1.0.18/dist/profiles/generic-hand/right.glb)
- [Проект WebXR Input Profiles](https://github.com/immersive-web/webxr-input-profiles/tree/main/packages/assets)
- [Лицензия MIT, Copyright (c) 2019 Amazon](licenses/webxr-input-profiles-assets-MIT.txt)

Превью получены рендером исходного GLB в Blender. Изменены только материал кожи, освещение и камера; форма сетки и исходная поза сохранены. Ретушь, новые детали кожи и изменение пропорций не применялись. Модель содержит 1360 вершин, 2314 полигонов и 25 суставов. Это базовая кисть для анимации, без фотореалистичной текстуры кожи.
