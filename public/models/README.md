# Полицейский по визуальному образцу

`officer-reference.glb` — самостоятельная 3D-модель, созданная по присланному изображению: гранёная синяя форма, фуражка, тёмные очки, подковообразные усы, золотой значок и пояс с подсумками. Рост — 1,958 м. Невидимые на изображении поверхности реконструированы, поэтому это приближённое воспроизведение, а не оригинальная модель с фотографии.

`officer-reference.blend` — редактируемая сцена Blender с моделью, скелетом и освещением для предпросмотра. GLB содержит только персонажа: 1606 треугольников и скелет из 16 костей. Все части имеют веса. Кисти целиком следуют костям рук; отдельных костей пальцев и готовых клипов анимации в этом варианте нет.

Это исходный вариант для просмотра и редактирования. В игре дежурный уже заменён его производной `src/assets/officer-duty.glb`: для неё добавлены отдельные кости пальцев и непрерывные рукава с весами на локтях. Посадка, печать, дыхание и поворот к монитору работают через скелет в `src/officer.js`. Подготовка игровой версии: `blender -b --factory-startup --python-exit-code 1 --python scripts/prepare-duty-officer.py`.

Повторная генерация из корня проекта:

```sh
blender -b --factory-startup --python-exit-code 1 --python scripts/build-reference-officer.py
```
